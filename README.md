# Puneet Sharma — Cloud & DevOps Engineer Portfolio

A responsive React + TypeScript + Vite portfolio concept based on the supplied brief.

## Run locally
1. Install Node.js 20 or newer.
2. Extract the ZIP.
3. In this folder run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.
5. Run `npm run build` to create a production build in `dist/`.

## Included
- Responsive dark editorial design system and mobile navigation
- Hero infrastructure illustration built with CSS/SVG
- About, technical expertise, 10 filterable project concepts, experience, credentials, testimonials and contact sections
- Detailed project case-study modal for all 10 concepts
- Contact form validation with honest frontend-demo feedback (no message is sent)
- SEO metadata, reduced-motion support and accessible labels

Project concepts are not verified production deployments. The social links are placeholders. No real GitHub repositories, live demos, resume file, backend, or email delivery integration is included. Replace all demo content before publishing.
